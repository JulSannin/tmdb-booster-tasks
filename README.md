# TMDB Booster

Веб-приложение для поиска и просмотра информации о фильмах на данных [TMDB](https://www.themoviedb.org/).

## Запуск локально

### 1. Установить зависимости

```bash
npm install
```

### 2. Добавить ключ TMDB

Создать файл `.env.local` в корне проекта:

```
VITE_TMDB_API_KEY=ваш_ключ
```

Префикс `VITE_` обязателен — без него переменная не попадёт в приложение.

Как получить ключ — в [описании задания](1-description.md).

### 3. Запустить

```bash
npm run dev
```

Приложение откроется на http://localhost:5173

## Структура проекта

Проект построен по методологии [Feature-Sliced Design](https://feature-sliced.design/). Слои упорядочены, импорты разрешены только вниз:

```
app       запуск приложения
pages     страницы
widgets   крупные самостоятельные блоки
features  действия пользователя
entities  сущности предметной области
shared    переиспользуемое без привязки к теме проекта
```

Слой заводится, когда в нём появляется код. Сейчас их два:

```
src/
├── app/
│   ├── App.tsx            корневой компонент
│   ├── index.ts           витрина слоя
│   └── styles/
│       └── global.css     глобальные стили
├── shared/
│   └── config/            адреса TMDB и переменные окружения
├── main.tsx               точка входа
└── vite-env.d.ts          типы переменных окружения
```

Соблюдение правил проверяется автоматически: `npm run fsd`.

Импорты внутри `src` пишутся через алиас `@`:

```ts
import { TMDB_BASE_URL } from '@/shared/config';
```
